Хранение

Записи лежат в файле в репозитории . Чтобы сайт мог их сохранять, нужен токен GitHub. Он хранится только в этом браузере и никуда, кроме api.github.com, не отправляется.

GitHub подключён.
  1. Откройте github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → выберите этот репозиторий.
  3. Permissions → Repository permissions → Contents: Read and write. Больше ничего не нужно.
  4. Выберите срок действия подольше, создайте токен и вставьте его сюда.
